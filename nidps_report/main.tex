\section*{Abstract}
Our project presents a Network Intrusion Detection and Prevention System, which protects small networks by combining signature-based methods and machine learning. The proposed solution uses the Suricata tool for known attack detection, applies Isolation Forest to identify anomalous behavior, and classifies the attacks with Random Forest and XGBoost algorithms. The analysis of encrypted traffic is accomplished by extracting flow-based features and TLS fingerprints, thus avoiding the need for traffic decryption. Experimental validation of the system was performed on multiple public intrusion detection datasets and real traffic with specific emphasis on detection accuracy, generalization capability, system overhead, and automated blocking of attacks on a low-resource servers.

\section*{Executive Summary}
\noindent The increasing use of IoT devices has made small networks more exposed to cyber security threats. Most home and small-office routers provide basic network protection, but they lack advanced intrusion detection and behavioural analysis. This project proposes a Network Intrusion Detection and Prevention System (NIDPS) that combines multiple detection techniques to provide better protection against both known and previously unseen attacks.

\noindent The proposed system runs on a Linux-based device acting as the wireless access point of the protected network. All client traffic passes through this device before reaching the ISP gateway. The NIDPS follows a three-layer detection approach. Suricata is used for signature-based detection of known attacks, Isolation Forest is used to identify abnormal network behaviour, and Random Forest or XGBoost is used to classify known attack types. The outputs of these layers are combined to decide whether traffic should be passed, reported as suspicious, or blocked.

\noindent The system is designed to detect attacks such as SSH brute force, port scanning, command-and-control beaconing, ARP spoofing, DNS spoofing, data exfiltration, DDoS, and lateral movement. Since most network traffic in modern networks is encrypted, the system uses features of flows and TLS fingerprints such as JA3 and JA3S instead of decrypting user traffic. This allows encrypted connections to be analysed while reducing privacy and performance concerns.

\noindent A major part of the project is the evaluation of machine learning models across different datasets. CIC-IDS-2017, CSE-CIC-IDS2018 and CIC-IoT-2023 are used for training and cross-dataset testing, while traffic collected from the actual deployment environment is used as an additional test set. The same flow extraction approach was used for all data sets and the production network to minimize differences in the training set and traffic under study.

\noindent When the system detects suspicious activity with a certain level of confidence, it can be configured to block the host that initiated the attack using iptables and ipset. Moreover, protection mechanisms such as temporary blocks, allow-lists or rate-limits can be applied. A watchdog and configurable failure handling mechanism are also present, which ensures network state integrity in case one of the monitoring components fails.

\noindent The project is evaluated using both detection and system performance measures. These include precision, recall, F1-score, false positive rate, forwarding latency, throughput, detection latency, blocking time, resource usage and recovery behaviour. The overall aim is to develop a practical and affordable NIDPS which combines signature-based detection, machine learning, automated prevention and failure handling for small networks.
