# NIDPS Decision Fusion & Enforcement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `services/decision/` (evidence fusion across Layers 1-3 into a per-flow Verdict, plus
a decaying per-host risk score) and `services/enforcer/` (turns BLOCK verdicts into `ipset` firewall
entries with allowlist protection, rate limiting, and exponential-backoff repeat-offense durations).

**Architecture:** Two independent long-running services connected only through Redis Streams and
SQLite, per the spec's Figure 6.4 class diagram. `DecisionEngine` consumes `Evidence` from
`STREAM_EVIDENCE` (published by other, already-planned phases), correlates it per flow over a short
window, runs Algorithm 5.5, maintains an in-memory per-host risk score (Eq 5.8), and publishes
`Verdict` onto `STREAM_VERDICTS` plus `HOST_SCORE_UPDATED` onto a new `STREAM_HOST_SCORES`.
`Enforcer` consumes BLOCK verdicts from `STREAM_VERDICTS`, runs Algorithm 5.6, and drives a real
`ipset` set via subprocess, writing `block_entry`/`audit_log` rows itself (the one part of the system
that owns synchronous DB writes outside the Event Store).

**Tech Stack:** Python 3.11+, `redis`/`fakeredis` (already in `requirements.txt` from the common
foundations phase), stdlib `sqlite3`, `subprocess`, `math`, `datetime`, `pytest`.

## Global Constraints

- Python 3.11+ (spec Table: Technology Stack). All timestamps are UTC ISO 8601 strings produced only
  via `common.schemas.utc_now_iso()` — never call `datetime.now()` directly in this plan's code.
- **Table ownership (per the master roadmap's cross-cutting rules):** `evidence` and `verdict` are
  normally written exactly once, by the (separate, later) Event Store subscribing to the bus. This
  plan's `Enforcer` is the one narrow, explicitly-justified exception: see "Verdict dual-write
  exception" below. `block_entry` and `audit_log` are owned entirely by this plan's `Enforcer`
  (full read/write). `allowlist_entry` and `host` are read-only for this plan except: `Enforcer` may
  seed 2-3 permanent `allowlist_entry` rows at startup (FR-7.3) and may upsert a minimal `host` row by
  `ip_address` for the `block_entry.host_id` FK — it never writes `host.risk_score`.
  `DecisionEngine` writes nothing to the database directly; it only publishes bus messages.
- **Verdict dual-write exception:** `block_entry.verdict_id` is a required FK to `verdict`, but the
  Event Store (a different, later phase) writes `verdict` rows asynchronously off the bus, and
  `Enforcer` needs a `verdict_id` to insert `block_entry` *synchronously*, within 1 second (NFR-4).
  Resolution: `Enforcer` derives a deterministic 63-bit integer from the bus envelope's
  `message_id` (a UUID4 string, already generated by `common.bus_messages.encode_envelope` for every
  message — see Phase 1) using `services/enforcer/verdict_sync.py::verdict_id_from_message_id()`
  (`uuid.UUID(message_id).int & 0x7FFFFFFFFFFFFFFF`), and inserts the `verdict` row itself with that
  explicit `verdict_id` via `INSERT OR IGNORE`, then inserts `block_entry` referencing the same id in
  the same transaction. **The Event Store's own future plan must replicate this exact function** and
  use `INSERT OR IGNORE INTO verdict (verdict_id, ...)` keyed on the same derived id when it later
  processes the identical bus message (same `message_id`, same envelope) — whichever of the two
  writers runs first wins the real row; the other's `INSERT OR IGNORE` is a no-op. This exception
  applies **only** to BLOCK-decision verdict messages that reach `Enforcer`; every ALERT/PASS verdict
  (and any ALERT verdict `Enforcer` itself emits when downgrading a rate-limited block) is written
  exactly once, by the Event Store, with no special handling.
- **Algorithm 5.5 evidence-to-field mapping (documented interpretation, since the signature-bridge,
  Layer-2, and Layer-3 components are built by other, parallel phases and only the `Evidence`
  dataclass shape is fixed, not a severity scale):**
  - `A(f) contains a drop rule or severity 1` (line 2) ⇒ any `Evidence` with `kind == SIGNATURE` and
    `strength >= 1.0`. By convention the signature-bridge component sets `strength = 1.0` exactly for
    a drop-rule/severity-1 match and a lower value (e.g. 0.25-0.75) for lower severities; this plan
    only checks the `>= 1.0` sentinel.
  - `A(f) ≠ ∅` (line 6) ⇒ any `Evidence` with `kind == SIGNATURE` for this flow, regardless of
    strength.
  - `s(f) ≥ τ` (lines 5-6) ⇒ any `Evidence` with `kind == ANOMALY` present for this flow. The
    Layer-2 anomaly detector (a different phase) is assumed to only publish `ANOMALY` evidence once
    its score has already crossed its own calibrated `τ` — this plan does not re-compare a raw score
    against `τ` itself.
  - `y, c` (lines 3-5) ⇒ `predicted_class`/`confidence` of the highest-confidence `Evidence` with
    `kind == CLASS` for this flow (there may be zero or more; ties broken by whichever `max()` picks
    first). `y == "Unknown"` is treated identically to `y == "Benign"` everywhere the algorithm checks
    `y ≠ Benign` — Layer 3 (a different phase) already labels low-confidence predictions "Unknown"
    rather than a real class name, per the task brief.
  - **Generalization beyond the literal pseudocode:** `EvidenceType.EXFIL` and `EvidenceType.BEACON`
    (both `Layer.L2_ANOMALY`-sourced, per the evidence contract) are treated the same as `ANOMALY` for
    the purposes of line 6's "add evidence to the host score" — the literal Algorithm 5.5 text only
    mentions `s(f)`, but FR-6.1 ("combine all three layers' results") and the existence of
    `risk.weight_exfil`/`risk.weight_beacon` config keys make clear these are meant to feed the same
    host-risk mechanism. This is a deliberate, documented extension, not a spec requirement to ignore.
  - **FR-6.4 (block at risk threshold) is layered on top of, not instead of, Algorithm 5.5's own BLOCK
    branches:** after any evidence is added to a host's risk score (line 7), if the resulting score is
    `>= risk.block_threshold`, `DecisionEngine.decide()` upgrades that flow's action from ALERT to
    BLOCK with `Layer.HOST` added to the attributed layers, instead of returning plain ALERT.
- **Config hot-reload (FR-10.6):** both services read every tunable via a small `CachedConfig` wrapper
  (`services/enforcer/config_cache.py`, imported by both packages — see below) with a 5-second TTL
  per key, backed by `common.config_loader.get()`, rather than reading once at startup.
- **Cross-import between the two packages:** `services/decision/` needs the allowlist check (line 1
  of Algorithm 5.5: "if f.src ∈ allowlist then return PASS") and the same config cache as
  `services/enforcer/`. Rather than introduce a third shared directory outside this plan's two
  assigned paths (`services/decision/`, `services/enforcer/`), `services/enforcer/` owns three small,
  dependency-free utility modules (`allowlist.py`, `config_cache.py`, `time_utils.py`) that
  `services/decision/` imports read-only. This is the one place the two packages are coupled; every
  other module in this plan belongs to exactly one of them.
- **Correlation window:** `EvidenceCorrelator`'s window (default 3.0s) is a constructor parameter, not
  a `CONFIG_SETTING` row — the task brief explicitly calls this a reasonable local design decision,
  not a hardcoded spec requirement, since Layer 1/2/3 evidence for one flow should all arrive within a
  few seconds of each other.
- **Allowlist seeding (FR-7.3):** `AllowlistStore.seed_system_entries()` takes `nidps_ip`,
  `gateway_ip`, `dns_ip` as explicit arguments (each optional). `services/enforcer/main.py` reads
  these from the environment variables `NIDPS_HOST_IP`, `NIDPS_GATEWAY_IP`, `NIDPS_DNS_IP` at startup
  if not otherwise supplied. Any address left `None` is simply not seeded (logged as a warning) —
  this plan assumes the deployment's systemd unit (a later phase) sets these three environment
  variables from the appliance's known network configuration; it is not this plan's job to discover
  them automatically.
- **Host upsert assumption:** when `Enforcer` creates a `host` row for an IP it has never seen before
  (needed only for the `block_entry.host_id` FK), it sets `is_internal = 1`, since only LAN-side
  devices are ever blocked by this appliance. It never sets or updates `risk_score`.
- **`Verdict.flow_id` type bridging:** `common.schemas.Verdict.flow_id` is typed `Optional[str]` but
  `verdict.flow_id` in the database is `INTEGER REFERENCES flow_record`. `Enforcer`'s synchronous
  verdict insert casts `verdict.flow_id` to `int` when it is a numeric string and to `NULL` otherwise
  (e.g. when a BLOCK verdict was produced by the host-risk-threshold path with no single flow_id) —
  this is a pragmatic bridge over a pre-existing type mismatch between Phase 1's dataclass and schema,
  not something this plan can or should fix.
- **Config keys consumed (names/defaults/ranges already fixed by `common/config_schema.py`, read via
  `common.config_loader.get()`, never hardcoded):** `fusion.theta_block` (0.90), `fusion.theta_alert`
  (0.70), `risk.half_life_s` (600), `risk.block_threshold` (6.0), `risk.weight_signature` (3.0),
  `risk.weight_anomaly` (2.0), `risk.weight_class` (2.5), `risk.weight_exfil` (2.0),
  `risk.weight_beacon` (2.5), `enforcement.base_block_s` (300), `enforcement.max_block_s` (86400),
  `enforcement.rate_limit_per_minute` (10), `watchdog.heartbeat_interval_s` (1.0). Evidence weights
  are carried on each `Evidence.weight` field by its producer (a different phase) using these same
  config values — this plan only ever reads `evidence.weight`, never re-derives it from the type.
- **Testing:** SQLite `:memory:` via `common.db.migrate.connect(":memory:")` for all DB tests;
  `fakeredis.FakeRedis(decode_responses=True)` wrapped in `common.bus.EventBus` for all bus tests;
  `IpsetClient`'s `run()` is always monkeypatched/injected in tests — no test calls a real `ipset`
  binary or requires root. Both `main.py` entry points accept an already-constructed `conn`/`bus`
  (dependency injection) precisely so integration tests can inspect database state afterward — a
  freshly-opened `:memory:` connection is private to that connection and cannot otherwise be inspected
  post-hoc from a second connection.

```python
"""ISO-8601 <-> epoch-seconds helpers shared by services/enforcer/enforcer.py and
services/decision/risk_tracker.py (see this plan's Global Constraints, 'Cross-import between the
two packages')."""
from __future__ import annotations

import time
from datetime import datetime, timedelta, timezone
from typing import Callable

ISO_FORMAT = "%Y-%m-%dT%H:%M:%S.%fZ"


def parse_iso(ts: str) -> datetime:
    return datetime.strptime(ts, ISO_FORMAT).replace(tzinfo=timezone.utc)


def format_iso(dt: datetime) -> str:
    return dt.strftime(ISO_FORMAT)


def iso_to_epoch(ts: str) -> float:
    return parse_iso(ts).timestamp()


def add_seconds_iso(ts: str, seconds: float) -> str:
    return format_iso(parse_iso(ts) + timedelta(seconds=seconds))


def epoch_hours_ago_iso(hours: float, now_fn: Callable[[], float] = time.time) -> str:
    now_dt = datetime.fromtimestamp(now_fn(), tz=timezone.utc)
    return format_iso(now_dt - timedelta(hours=hours))
```

```python
"""Short-TTL cache over common.config_loader.get(), so FR-10.6 (apply config changes without
restart) is satisfied without re-querying SQLite on every flow/verdict."""
from __future__ import annotations

import sqlite3
import time
from typing import Callable, Union

from common import config_loader

Number = Union[int, float]


class CachedConfig:
    def __init__(
        self,
        conn: sqlite3.Connection,
        ttl_s: float = 5.0,
        now_fn: Callable[[], float] = time.time,
    ):
        self._conn = conn
        self._ttl_s = ttl_s
        self._now_fn = now_fn
        self._cache: dict[str, tuple[float, Union[Number, str, bool]]] = {}

    def get(self, key: str) -> Union[Number, str, bool]:
        now = self._now_fn()
        cached = self._cache.get(key)
        if cached is not None and now - cached[0] < self._ttl_s:
            return cached[1]
        value = config_loader.get(self._conn, key)
        self._cache[key] = (now, value)
        return value
```

```python
"""Thin subprocess wrapper over the ipset CLI (FR-7.1, FR-7.2). The ipset set itself relies on
its own 'timeout' feature to auto-expire blocks -- this plan never builds a separate expiry
poller to remove entries early; see Enforcer.reconcile_expired_blocks() for the DB-side status
bookkeeping that follows an expiry after the fact."""
from __future__ import annotations

import subprocess
from typing import Callable, Optional

Runner = Callable[[list], object]


class IpsetClient:
    def __init__(self, set_name: str = "nidps_blocklist", runner: Optional[Runner] = None):
        self._set_name = set_name
        self._runner = runner or self._default_runner

    @staticmethod
    def _default_runner(argv: list) -> object:
        return subprocess.run(argv, capture_output=True, text=True, check=False)

    def run(self, argv: list) -> object:
        return self._runner(argv)

    def ensure_set_exists(self) -> None:
        self.run(["ipset", "create", self._set_name, "hash:ip", "timeout", "0", "-exist"])

    def add(self, ip: str, timeout_s: int) -> None:
        self.run(["ipset", "add", self._set_name, ip, "timeout", str(int(timeout_s)), "-exist"])

    def remove(self, ip: str) -> None:
        self.run(["ipset", "del", self._set_name, ip])
```

```python
"""Buffers Evidence by flow_id for a short window so Layer 1/2/3 evidence for the SAME flow is
fused together by DecisionEngine.decide() rather than each layer's evidence producing its own
verdict. Evidence with no flow_id (e.g. host-level ARP evidence) has nothing to correlate with,
so it is returned for immediate processing instead of waiting out the window."""
from __future__ import annotations

import time
import uuid
from typing import Callable, Optional

from common.schemas import Evidence

CorrelationGroup = tuple  # (key: str, host_ip: str, flow_id: Optional[str], items: list[Evidence])


class EvidenceCorrelator:
    def __init__(self, window_s: float = 3.0, now_fn: Callable[[], float] = time.time):
        self._window_s = window_s
        self._now_fn = now_fn
        self._buffers: dict[str, dict] = {}

    def add(self, evidence: Evidence) -> Optional[CorrelationGroup]:
        if evidence.flow_id is None:
            key = f"noflow:{evidence.host_ip}:{uuid.uuid4()}"
            return key, evidence.host_ip, None, [evidence]

        key = evidence.flow_id
        bucket = self._buffers.setdefault(
            key, {"first_ts": self._now_fn(), "host_ip": evidence.host_ip, "items": []}
        )
        bucket["items"].append(evidence)
        return None

    def due(self) -> list[CorrelationGroup]:
        now = self._now_fn()
        ready: list[CorrelationGroup] = []
        for key, bucket in list(self._buffers.items()):
            if now - bucket["first_ts"] >= self._window_s:
                ready.append((key, bucket["host_ip"], key, bucket["items"]))
                del self._buffers[key]
        return ready
```

```python
"""Per-host decaying risk score (Eq 5.8): S_h(t) = S_h(t_prev) * e^(-lambda*(t-t_prev)) + w_v,
lambda = ln(2) / half_life_s. Maintains the authoritative in-memory score and publishes
HOST_SCORE_UPDATED on every change so the (separate) Event Store can persist it to
host.risk_score -- this class never writes to the database itself (FR-6.3)."""
from __future__ import annotations

import math
import sqlite3
import time
from typing import Callable

from common.bus import STREAM_HOST_SCORES, EventBus
from common.bus_messages import MessageType, encode_envelope
from common.schemas import utc_now_iso

from services.enforcer.time_utils import iso_to_epoch


class RiskScoreTracker:
    def __init__(
        self,
        conn: sqlite3.Connection,
        bus: EventBus,
        config_getter: Callable[[str], float],
        now_fn: Callable[[], float] = time.time,
    ):
        self._conn = conn
        self._bus = bus
        self._config_getter = config_getter
        self._now_fn = now_fn
        self._scores: dict[str, tuple[float, float]] = {}

    def _seed_if_needed(self, host_ip: str) -> None:
        if host_ip in self._scores:
            return
        row = self._conn.execute(
            "SELECT risk_score, last_seen FROM host WHERE ip_address = ?", (host_ip,)
        ).fetchone()
        if row is None or row[1] is None:
            self._scores[host_ip] = (0.0, self._now_fn())
        else:
            score, last_seen = row
            self._scores[host_ip] = (score, iso_to_epoch(last_seen))

    def current_score(self, host_ip: str) -> float:
        self._seed_if_needed(host_ip)
        score, last_ts = self._scores[host_ip]
        half_life = self._config_getter("risk.half_life_s")
        lam = math.log(2) / half_life
        elapsed = max(0.0, self._now_fn() - last_ts)
        return score * math.exp(-lam * elapsed)

    def add_evidence(self, host_ip: str, weight: float) -> float:
        decayed = self.current_score(host_ip)
        new_score = decayed + weight
        self._scores[host_ip] = (new_score, self._now_fn())
        self._publish_update(host_ip, new_score)
        return new_score

    def _publish_update(self, host_ip: str, score: float) -> None:
        payload = {"host_ip": host_ip, "risk_score": score, "timestamp": utc_now_iso()}
        self._bus.publish(
            STREAM_HOST_SCORES, encode_envelope(MessageType.HOST_SCORE_UPDATED, payload)
        )
```

```python
"""DecisionEngine.decide() implements Algorithm 5.5 (per-flow verdict). See this plan's Global
Constraints for the documented mapping from the literal pseudocode's A(f)/s(f)/y/c notation onto
Evidence fields, and for the FR-6.4 host-risk-threshold escalation layered on top of it."""
from __future__ import annotations

from typing import Callable, Optional

from common.schemas import Action, Evidence, EvidenceType, Layer, Verdict

BENIGN_LIKE = {None, "Benign", "Unknown"}
L1_BLOCK_STRENGTH_THRESHOLD = 1.0


class DecisionEngine:
    def __init__(
        self,
        risk_tracker,
        is_allowlisted: Callable[[str], bool],
        config_getter: Callable[[str], float],
    ):
        self._risk_tracker = risk_tracker
        self._is_allowlisted = is_allowlisted
        self._config_getter = config_getter
        self.hostScores: dict[str, float] = {}

    def decide(self, flow_id: Optional[str], host_ip: str, evidence: list[Evidence]) -> Verdict:
        if self._is_allowlisted(host_ip):
            return Verdict(
                action=Action.PASS,
                layers=[],
                explanation=f"{host_ip} is allowlisted; traffic is never inspected for blocking.",
                flow_id=flow_id,
                host_ip=host_ip,
            )

        l1_block = [
            e for e in evidence
            if e.kind == EvidenceType.SIGNATURE and e.strength >= L1_BLOCK_STRENGTH_THRESHOLD
        ]
        if l1_block:
            return Verdict(
                action=Action.BLOCK,
                layers=[Layer.L1_SIGNATURE],
                attack_class="signature-match",
                explanation=(
                    "Layer 1 (Suricata) matched a drop-rule/critical-severity signature on this "
                    "flow; blocking immediately."
                ),
                flow_id=flow_id,
                host_ip=host_ip,
            )

        class_evidence = [e for e in evidence if e.kind == EvidenceType.CLASS]
        best_class = max(class_evidence, key=lambda e: e.confidence or 0.0, default=None)
        y = best_class.predicted_class if best_class else None
        c = best_class.confidence if best_class else 0.0
        y_actionable = y not in BENIGN_LIKE

        theta_block = self._config_getter("fusion.theta_block")
        theta_alert = self._config_getter("fusion.theta_alert")

        if y_actionable and c >= theta_block:
            return Verdict(
                action=Action.BLOCK,
                layers=[Layer.L3_CLASSIFIER],
                attack_class=y,
                explanation=(
                    f"Layer 3 classifier identified this flow as '{y}' with confidence "
                    f"{c:.2f} (>= block threshold {theta_block:.2f})."
                ),
                flow_id=flow_id,
                host_ip=host_ip,
            )

        anomaly_evidence = [e for e in evidence if e.kind == EvidenceType.ANOMALY]
        if anomaly_evidence and y_actionable and c >= theta_alert:
            return Verdict(
                action=Action.BLOCK,
                layers=[Layer.L2_ANOMALY, Layer.L3_CLASSIFIER],
                attack_class=y,
                explanation=(
                    f"Layer 2 flagged this flow as anomalous and Layer 3 classified it as '{y}' "
                    f"with confidence {c:.2f} (>= alert threshold {theta_alert:.2f}); L2+L3 "
                    f"agreement triggers an immediate block."
                ),
                flow_id=flow_id,
                host_ip=host_ip,
            )

        signature_evidence = [e for e in evidence if e.kind == EvidenceType.SIGNATURE]
        other_evidence = [
            e for e in evidence if e.kind in (EvidenceType.EXFIL, EvidenceType.BEACON)
        ]
        contributing = list(anomaly_evidence) + list(signature_evidence) + list(other_evidence)
        if y_actionable and c >= theta_alert and all(best_class is not e for e in contributing):
            contributing.append(best_class)

        if contributing:
            layers = sorted({e.source for e in contributing})
            current_score = 0.0
            for e in contributing:
                current_score = self._risk_tracker.add_evidence(host_ip, e.weight)
            self.hostScores[host_ip] = current_score

            reasons = ", ".join(sorted(f"{e.kind.value} from {e.source.value}" for e in contributing))
            block_threshold = self._config_getter("risk.block_threshold")
            if current_score >= block_threshold:
                return Verdict(
                    action=Action.BLOCK,
                    layers=sorted(set(layers) | {Layer.HOST}),
                    attack_class=y if y_actionable else None,
                    explanation=(
                        f"Host {host_ip} risk score reached {current_score:.2f} "
                        f"(>= block threshold {block_threshold:.2f}) after new evidence "
                        f"({reasons}); blocking the host."
                    ),
                    flow_id=flow_id,
                    host_ip=host_ip,
                )
            return Verdict(
                action=Action.ALERT,
                layers=layers,
                attack_class=y if y_actionable else None,
                explanation=(
                    f"Suspicious evidence observed ({reasons}) but below block thresholds; "
                    f"host risk score now {current_score:.2f}/{block_threshold:.2f}."
                ),
                flow_id=flow_id,
                host_ip=host_ip,
            )

        return Verdict(
            action=Action.PASS,
            layers=[],
            explanation="No signature, anomaly, or classifier evidence met alert thresholds.",
            flow_id=flow_id,
            host_ip=host_ip,
        )

    def addHostEvidence(self, host_ip: str, weight: float) -> float:
        new_score = self._risk_tracker.add_evidence(host_ip, weight)
        self.hostScores[host_ip] = new_score
        return new_score
```

```python
"""Enforcer.enforce() implements Algorithm 5.6 (enforce a BLOCK verdict). Owns block_entry and
audit_log (FR-7.6) and the one explicitly-justified synchronous write to verdict (see this plan's
Global Constraints, 'Verdict dual-write exception')."""
from __future__ import annotations

import json
import logging
import sqlite3
import time
from collections import deque
from typing import Callable, Optional

from common.bus import STREAM_VERDICTS, EventBus
from common.bus_messages import MessageType, encode_envelope
from common.schemas import Action, BlockEntry, Verdict, utc_now_iso

from services.enforcer.allowlist import AllowlistStore
from services.enforcer.ipset_client import IpsetClient
from services.enforcer.time_utils import add_seconds_iso, epoch_hours_ago_iso
from services.enforcer.verdict_sync import verdict_id_from_message_id

logger = logging.getLogger("enforcer")


class Enforcer:
    def __init__(
        self,
        conn: sqlite3.Connection,
        ipset_client: IpsetClient,
        allowlist: AllowlistStore,
        config_getter: Callable[[str], float],
        bus: EventBus,
        now_fn: Callable[[], float] = time.time,
    ):
        self._conn = conn
        self._ipset = ipset_client
        self.allowlist = allowlist
        self._config_getter = config_getter
        self._bus = bus
        self._now_fn = now_fn
        self._recent_block_times: deque = deque()
        self.maxBlocksPerMinute: Optional[int] = None

    def _upsert_host(self, ip: str) -> int:
        now = utc_now_iso()
        self._conn.execute(
            "INSERT OR IGNORE INTO host (ip_address, is_internal, first_seen, last_seen) "
            "VALUES (?, 1, ?, ?)",
            (ip, now, now),
        )
        self._conn.execute("UPDATE host SET last_seen = ? WHERE ip_address = ?", (now, ip))
        row = self._conn.execute("SELECT host_id FROM host WHERE ip_address = ?", (ip,)).fetchone()
        return row[0]

    def _write_audit(self, action: str, target: str, new_value: Optional[str] = None) -> None:
        self._conn.execute(
            "INSERT INTO audit_log (user_id, action, target, old_value, new_value, timestamp) "
            "VALUES (NULL, ?, ?, NULL, ?, ?)",
            (action, target, new_value, utc_now_iso()),
        )

    def _offence_count_24h(self, host_id: int) -> int:
        cutoff = epoch_hours_ago_iso(24, now_fn=self._now_fn)
        row = self._conn.execute(
            "SELECT COUNT(*) FROM block_entry WHERE host_id = ? AND start_time >= ?",
            (host_id, cutoff),
        ).fetchone()
        return row[0]

    def _prune_recent_blocks(self) -> None:
        now = self._now_fn()
        while self._recent_block_times and now - self._recent_block_times[0] > 60.0:
            self._recent_block_times.popleft()

    def _verdict_flow_id_int(self, verdict: Verdict) -> Optional[int]:
        if verdict.flow_id is not None and str(verdict.flow_id).isdigit():
            return int(verdict.flow_id)
        return None

    def enforce(self, verdict: Verdict, message_id: str) -> Optional[BlockEntry]:
        host_ip = verdict.host_ip
        self.maxBlocksPerMinute = self._config_getter("enforcement.rate_limit_per_minute")

        if self.allowlist.contains(host_ip):
            logger.info("block suppressed: %s is allowlisted", host_ip)
            self._write_audit("BLOCK_SKIPPED_ALLOWLIST", host_ip, new_value=verdict.explanation)
            self._conn.commit()
            return None

        self._prune_recent_blocks()
        if len(self._recent_block_times) >= self.maxBlocksPerMinute:
            logger.warning(
                "block rate limit exceeded (%d blocks in the last minute, max %d); "
                "downgrading %s to ALERT",
                len(self._recent_block_times), self.maxBlocksPerMinute, host_ip,
            )
            self._write_audit("BLOCK_RATE_LIMITED", host_ip, new_value=verdict.explanation)
            self._conn.commit()
            downgraded = Verdict(
                action=Action.ALERT,
                layers=verdict.layers,
                explanation=(
                    f"Block suppressed by rate limit ({self.maxBlocksPerMinute}/min exceeded); "
                    f"raised as ALERT instead. Original reason: {verdict.explanation}"
                ),
                flow_id=verdict.flow_id,
                host_ip=host_ip,
                attack_class=verdict.attack_class,
            )
            self._bus.publish(STREAM_VERDICTS, encode_envelope(MessageType.VERDICT, downgraded))
            return None

        host_id = self._upsert_host(host_ip)
        n = self._offence_count_24h(host_id)
        base = self._config_getter("enforcement.base_block_s")
        max_d = self._config_getter("enforcement.max_block_s")
        duration = min(base * (2 ** n), max_d)

        verdict_id = verdict_id_from_message_id(message_id)
        layers_json = json.dumps([layer.value for layer in verdict.layers])
        self._conn.execute(
            """INSERT OR IGNORE INTO verdict
               (verdict_id, flow_id, host_id, decision, layers, attack_class, explanation, created_at)
               VALUES (?, ?, ?, ?, ?, ?, ?, ?)""",
            (
                verdict_id,
                self._verdict_flow_id_int(verdict),
                host_id,
                verdict.action.value,
                layers_json,
                verdict.attack_class,
                verdict.explanation,
                verdict.timestamp,
            ),
        )

        start_time = utc_now_iso()
        expires_at = add_seconds_iso(start_time, duration)
        self._conn.execute(
            """INSERT INTO block_entry
               (host_id, verdict_id, offence_count, duration_s, start_time, expires_at, status)
               VALUES (?, ?, ?, ?, ?, ?, 'ACTIVE')""",
            (host_id, verdict_id, n, duration, start_time, expires_at),
        )
        self._write_audit(
            "BLOCK", host_ip, new_value=f"duration_s={duration} offence_count={n}"
        )
        self._conn.commit()

        self._ipset.add(host_ip, duration)
        self._recent_block_times.append(self._now_fn())

        return BlockEntry(ip=host_ip, reason=verdict.explanation, duration_s=duration, offence_count=n)

    def unblock(self, ip: str, released_by: Optional[int] = None) -> None:
        row = self._conn.execute(
            """SELECT block_entry.block_id FROM block_entry
               JOIN host ON host.host_id = block_entry.host_id
               WHERE host.ip_address = ? AND block_entry.status = 'ACTIVE'
               ORDER BY block_entry.start_time DESC LIMIT 1""",
            (ip,),
        ).fetchone()

        self._ipset.remove(ip)
        now = utc_now_iso()
        if row is not None:
            self._conn.execute(
                "UPDATE block_entry SET status = 'RELEASED', released_by = ?, released_at = ? "
                "WHERE block_id = ?",
                (released_by, now, row[0]),
            )
        self._write_audit("BLOCK_RELEASED", ip, new_value=f"released_by={released_by}")
        self._conn.commit()

    def reconcile_expired_blocks(self) -> int:
        now = utc_now_iso()
        cursor = self._conn.execute(
            "UPDATE block_entry SET status = 'EXPIRED' WHERE status = 'ACTIVE' AND expires_at <= ?",
            (now,),
        )
        self._conn.commit()
        return cursor.rowcount
```

```python
"""Decision service entry point: consumes Evidence from STREAM_EVIDENCE with consumer group
'decision-engine', correlates it per flow, runs DecisionEngine.decide(), and publishes Verdict
onto STREAM_VERDICTS plus a heartbeat onto STREAM_HEARTBEATS at watchdog.heartbeat_interval_s."""
from __future__ import annotations

import time
from typing import Optional

from common.bus import STREAM_EVIDENCE, STREAM_HEARTBEATS, STREAM_VERDICTS, EventBus
from common.bus_messages import MessageType, decode_envelope, encode_envelope
from common.config_loader import seed_defaults
from common.db.migrate import connect
from common.logging_setup import configure_logging
from common.schemas import ComponentHealth, Evidence, EvidenceType, HealthState, Layer, utc_now_iso

from services.decision.correlator import EvidenceCorrelator
from services.decision.engine import DecisionEngine
from services.decision.risk_tracker import RiskScoreTracker
from services.enforcer.allowlist import AllowlistStore
from services.enforcer.config_cache import CachedConfig

COMPONENT_NAME = "decision-engine"
CONSUMER_GROUP = "decision-engine"


def _evidence_from_payload(payload: dict) -> Evidence:
    return Evidence(
        source=Layer(payload["source"]),
        flow_id=payload.get("flow_id"),
        host_ip=payload["host_ip"],
        kind=EvidenceType(payload["kind"]),
        strength=payload["strength"],
        weight=payload["weight"],
        timestamp=payload.get("timestamp", utc_now_iso()),
        signature_id=payload.get("signature_id"),
        predicted_class=payload.get("predicted_class"),
        confidence=payload.get("confidence"),
        model_id=payload.get("model_id"),
    )


def run(
    conn=None,
    bus: Optional[EventBus] = None,
    db_path: str = "nidps.db",
    redis_url: str = "redis://localhost:6379/0",
    correlation_window_s: float = 3.0,
    poll_interval_s: float = 0.5,
    stop_after_iterations: Optional[int] = None,
) -> None:
    logger = configure_logging(COMPONENT_NAME)
    conn = conn or connect(db_path)
    seed_defaults(conn)
    bus = bus or EventBus.from_url(redis_url)

    config_cache = CachedConfig(conn)
    allowlist = AllowlistStore(conn)
    risk_tracker = RiskScoreTracker(conn, bus, config_cache.get)
    engine = DecisionEngine(risk_tracker, allowlist.contains, config_cache.get)
    correlator = EvidenceCorrelator(window_s=correlation_window_s)

    def _flush(host_ip, flow_id, items):
        verdict = engine.decide(flow_id, host_ip, items)
        bus.publish(STREAM_VERDICTS, encode_envelope(MessageType.VERDICT, verdict))
        logger.info(
            "verdict %s for host=%s flow=%s: %s",
            verdict.action.value, host_ip, flow_id, verdict.explanation,
        )

    def handle_raw(raw: str) -> None:
        envelope = decode_envelope(raw)
        if envelope["type"] != MessageType.EVIDENCE.value:
            return
        evidence = _evidence_from_payload(envelope["payload"])
        ready = correlator.add(evidence)
        if ready is not None:
            _key, host_ip, flow_id, items = ready
            _flush(host_ip, flow_id, items)

    last_heartbeat = 0.0
    iterations = 0
    while stop_after_iterations is None or iterations < stop_after_iterations:
        bus.consume(
            STREAM_EVIDENCE,
            group=CONSUMER_GROUP,
            consumer=f"{CONSUMER_GROUP}-1",
            handler=handle_raw,
            block_ms=int(poll_interval_s * 1000),
        )
        for _key, host_ip, flow_id, items in correlator.due():
            _flush(host_ip, flow_id, items)

        now = time.time()
        heartbeat_interval = config_cache.get("watchdog.heartbeat_interval_s")
        if now - last_heartbeat >= heartbeat_interval:
            health = ComponentHealth(
                name=COMPONENT_NAME, state=HealthState.NORMAL, last_heartbeat=utc_now_iso()
            )
            bus.publish(STREAM_HEARTBEATS, encode_envelope(MessageType.HEARTBEAT, health))
            last_heartbeat = now
        iterations += 1


if __name__ == "__main__":
    run()
```

```python
"""Enforcer service entry point: consumes BLOCK verdicts from STREAM_VERDICTS with consumer
group 'enforcer', runs Enforcer.enforce(), periodically reconciles expired block_entry rows, and
publishes a heartbeat onto STREAM_HEARTBEATS at watchdog.heartbeat_interval_s. Seeds the three
permanent allowlist entries (FR-7.3) from NIDPS_HOST_IP / NIDPS_GATEWAY_IP / NIDPS_DNS_IP at
startup if not otherwise supplied."""
from __future__ import annotations

import os
import time
from typing import Optional

from common.bus import STREAM_HEARTBEATS, STREAM_VERDICTS, EventBus
from common.bus_messages import MessageType, decode_envelope, encode_envelope
from common.config_loader import seed_defaults
from common.db.migrate import connect
from common.logging_setup import configure_logging

from services.enforcer.ipset_client import IpsetClient

COMPONENT_NAME = "enforcer"
CONSUMER_GROUP = "enforcer"


def _verdict_from_payload(payload: dict) -> Verdict:
    return Verdict(
        action=Action(payload["action"]),
        layers=[Layer(layer) for layer in payload["layers"]],
        explanation=payload["explanation"],
        flow_id=payload.get("flow_id"),
        host_ip=payload.get("host_ip"),
        attack_class=payload.get("attack_class"),
        timestamp=payload.get("timestamp", utc_now_iso()),
    )


def run(
    conn=None,
    bus: Optional[EventBus] = None,
    db_path: str = "nidps.db",
    redis_url: str = "redis://localhost:6379/0",
    nidps_ip: Optional[str] = None,
    gateway_ip: Optional[str] = None,
    dns_ip: Optional[str] = None,
    ipset_runner=None,
    poll_interval_s: float = 0.5,
    stop_after_iterations: Optional[int] = None,
) -> None:
    logger = configure_logging(COMPONENT_NAME)
    conn = conn or connect(db_path)
    seed_defaults(conn)
    bus = bus or EventBus.from_url(redis_url)

    config_cache = CachedConfig(conn)
    allowlist = AllowlistStore(conn)

    nidps_ip = nidps_ip or os.environ.get("NIDPS_HOST_IP")
    gateway_ip = gateway_ip or os.environ.get("NIDPS_GATEWAY_IP")
    dns_ip = dns_ip or os.environ.get("NIDPS_DNS_IP")
    if not (nidps_ip and gateway_ip and dns_ip):
        logger.warning(
            "one or more of NIDPS_HOST_IP/NIDPS_GATEWAY_IP/NIDPS_DNS_IP is unset; "

    ipset_client = IpsetClient(runner=ipset_runner) if ipset_runner else IpsetClient()
    ipset_client.ensure_set_exists()

    enforcer = Enforcer(conn, ipset_client, allowlist, config_cache.get, bus)

    def handle_raw(raw: str) -> None:
        envelope = decode_envelope(raw)
        if envelope["type"] != MessageType.VERDICT.value:
            return
        verdict = _verdict_from_payload(envelope["payload"])
        if verdict.action != Action.BLOCK:
            return
        enforcer.enforce(verdict, envelope["message_id"])

    last_heartbeat = 0.0
    iterations = 0
    while stop_after_iterations is None or iterations < stop_after_iterations:
        bus.consume(
            STREAM_VERDICTS,
            group=CONSUMER_GROUP,
            consumer=f"{CONSUMER_GROUP}-1",
            handler=handle_raw,
            block_ms=int(poll_interval_s * 1000),
        )

        now = time.time()

        if now - last_heartbeat >= heartbeat_interval:

            )
            bus.publish(STREAM_HEARTBEATS, encode_envelope(MessageType.HEARTBEAT, health))
            last_heartbeat = now
        iterations += 1


if __name__ == "__main__":
    run()
```
